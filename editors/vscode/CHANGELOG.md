# Change Log

All notable changes to the "funnelscript-lang" extension will be documented in this file.

## [0.1.0] - 2026-11-22

- Initial release of FunnelScript editor support.
- Full syntax highlighting for `.fnls` source files synchronized with `tokens.py` and grammar specifications.
- Official brand icon integration for file explorer and editor tabs (Signal Violet `#725CFF`, Dark, Light).
- Lightweight `funnelscript-icons` file icon theme.
- Language configuration: Line comments (`//`, `#`), block comments (`/* */`), bracket matching, and auto-closing quotes and generic pairs (`< >`).
