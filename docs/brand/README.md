# FunnelScript Visual Identity — v1.0

## Identity

**FunnelScript** is an experimental programming language for typed, event-driven World models. Its geometric Convergence mark presents three independent event streams converging on an explicit output node. It refers to inspectable execution, **not** a marketing funnel, monetary gain, forecasting guarantees or empirically calibrated outcomes.

## Core color tokens

| Token | Hex | Usage |
|---|---|---|
| Signal Violet | `#725CFF` | Primary brand, mark, UI primary action |
| Accessible Violet | `#6D54F5` | White-text buttons and violet text on light surfaces (WCAG AA) |
| Graphite | `#121525` | Dark surface, light-mode headings |
| Event Mint | `#61E7C3` | Sparse terminal accent on dark |
| Cloud | `#F6F7FB` | Light surfaces and documentation |
| White | `#FFFFFF` | Contrast and reversed logo |

The primary `#725CFF` is an iconic logo/accent color, not the default for small light-mode text or white-text buttons; use `#6D54F5` for those accessible interactive contexts. Use a restrained 70% neutral / 25% violet / 5% mint visual balance. Use violet + white for a simple 16 px favicon; do not use mint as small text on white. Retain semantic colors for danger/success/warnings independently from the identity accents.

## Typography

- Interface: **Inter / Inter Display** where installed, then system sans-serif; ordinary text 400–500, headings 600–700.
- Code: **IBM Plex Mono** where installed, then platform UI monospace.
- Protected wordmark is **FunnelScript**, with capital F and S; SVG wordmark files contain vector glyph outlines, not a bundled font file.

## Usage

- Use `assets/brand/funnelscript-wordmark-light.svg` for light README/documentation surfaces.
- Use `assets/brand/funnelscript-wordmark-dark.svg` on graphite / dark backgrounds.
- Use `assets/brand/funnelscript-icon-color.svg` for standalone transparent marks.
- Use `assets/brand/funnelscript-favicon.svg` for tiny app icon and tab contexts.
- `assets/brand/funnelscript-icon-mono.svg` is suitable for a single-ink use.
- Keep symbol clear space of at least one-quarter of its visible width; minimum recommended standalone symbol size is 20 px.
- Do not change proportions, skew, rotate, add gradients or shadows, or turn the icon into a literal monetary funnel.

**Voice:** Precise, composed, technical, approachable. Avoid unfounded scientific claims. Primary descriptive line: **Systems, expressed as code.** Secondary: **One language. Explicit states. Verifiable flows.**

This is a project design-system implementation, not a registration, certification or trademark-clearance assertion. Any future brand changes should update this contract and all dependent assets consistently.
